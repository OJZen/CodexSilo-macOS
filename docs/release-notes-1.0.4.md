# CodexSilo 1.0.4

本次更新聚焦可观测性和代理页体验，让排障更直接、代理页面更简洁。

## 更新内容

- 新增本地文件日志系统，关键流程、错误和代理状态变化会写入应用日志目录
- 设置页新增独立 Logs 页面，支持刷新、复制、清空和打开日志文件夹
- 收紧代理热路径日志，正常请求不再刷出过多成功明细
- 优化代理页面布局，去掉多余卡片层级，并为主要内容卡片补充更柔和的背景色

## 安装

1. 下载 `CodexSilo-1.0.4-macOS-notarized.zip`
2. 解压后将 `CodexSilo.app` 拖入 `Applications`
3. 首次打开时按系统提示授权运行
